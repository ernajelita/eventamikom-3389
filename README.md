## 📋 Tentang Project

EventAmikom adalah platform digital untuk manajemen tiket event, dikembangkan sebagai bagian dari praktikum mata kuliah **Digital Business**. Project ini mendemonstrasikan alur bisnis penjualan tiket secara digital, mulai dari sisi pengguna hingga panel administrasi.
